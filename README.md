# Flow — Block Distractions on YouTube, Reddit & X (Twitter)

Regain control of your browsing. Flow blocks addictive feeds and recommendations while keeping search and essential features!

## Features

*   **YouTube Blocking**: Hide recommendations, Shorts, community posts, comments, notifications, and more. Granular controls let you choose exactly what to block.
*   **Reddit Blocking**: Block home feed, recent posts, comments, sidebar, and nav bar. Keep Reddit useful without getting sucked in.
*   **X (Twitter) Blocking**: Hide your home timeline feed, trending topics, "Who to follow" recommendations, and non-essential sidebar navigation tabs.
*   **New Tab Blocker**: Automatically close blank new tabs. Links you intentionally open in new tabs are never affected.

## Privacy First
No tracking, no data collection, no analytics. Your browsing stays local.

Works on: Chrome, Edge, Brave, and other Chromium browsers.

## How to use
1. Install and pin Flow to your toolbar
2. Click the icon to open settings
3. Choose "Global Settings" to enable all features, or select YouTube, Reddit, or X individually for fine-grained control

*Note: some features require a page refresh.*
